# 牌效率

## 牌效率理论

### 牌效率基础：面子与搭子

牌效率的核心在于通过组牌技术，使手牌尽快达成“4个面子 + 1个雀头”的胡牌型。

* **面子构成效率**：组成顺子的难度远低于刻子。单张牌（如5万）凑顺子的进牌张数远多于刻子。
* **搭子价值排序**：**两面 (8张) >> 嵌张 (4张) > 边张 (4张)**。
* **改良潜力**：中心位置的嵌张（如46）优于靠边嵌张（如13），因为前者有双向转化为两面的潜力。

### 核心架构：五组理论 (5-Block Theory)

* **基本定义**：将手牌拆解为5组（4面子+1雀头），以整体视角审视进度。
* **搭子过多处理**：当手牌存在6组或更多组合时，应拆掉最弱的一组（如边张、愚型搭子）为好型腾出空间。
* **五组 vs 六组打法**：
* **两向听阶段**：六组打法通常拥有更多的进张数。
* **一向听阶段**：五组打法更容易形成“完全一向听”，进张数极多且听牌速度平均快约 0.28 巡。

### 舍牌逻辑与“有效牌重复”回避

在序盘处理多余单张牌时，除了基本价值排序，必须考虑**有效牌重复（二度受）**。

1. **基础价值排序（由低到高）**：

   * **客风牌**：无役且进牌能力差。
   * **幺九牌 (1, 9)**：进牌效率低，无法组成两面搭子。
   * **役牌**：可提供一翻（役）并解决胡牌问题。
   * **尖张 (2, 8) 与 中心数牌 (3-7)**：成搭能力最强。

2. **重叠回避原则 (Nidou-uke)**：

   * **筋牌重叠**：若持有 `1、4` 或 `6、9`，其进张范围（如2、3）严重重叠。此时 **1或9的价值甚至低于客风牌**，应优先舍弃。
   * **搭子重叠**：如同时持有 `12p` 和 `45p`，两者都需 `3p` 才能成顺。
   * **复合型重叠处理**：
   * `1334` 型：拆掉 `1` 留下 `334` 复合型。
   * `1224` 型：拆掉 `1` 留下 `224` 嵌张对子，减小组牌压力。

* **例外情况**：若重叠的有效牌是**宝牌 (Dora)**，可考虑保留重叠结构以增加同时使用多张宝牌的机会，提升打点。

### 对子处理与强力复合型

* **对子法则**：**两个对子最舒服**（利用双碰效应），**三个对子拆一双**（提升进张面）。
* **优秀复合型（面子+单张/搭子）**：
* **四连型 (3456)**：最强复合型，进张极广且具备延伸单骑性质。
* **中膨型 (3445)**：进张广且具“一盃口”潜力，强度仅次于四连型。
* **螺丝型 (3444)**：听牌时具备多面听潜力（如听2、3、5），是变对为面的利器。
* **跳张型 (3567)**：兼具极强的改良能力，强度优于单张 2/8。

### 一向听集中理论 (巅峰理论)

* **核心策略**：从一向听到听牌是难度最高的阶段，应将资源最大程度集中于此。
* **牺牲与交换**：宁愿在两向听阶段牺牲一部分进张数，也要确保在一向听阶段拥有 20 张甚至更多的有效进张。
* **完全一向听**：由两个两面搭子、一个对子复合型及一个独立对子组成，是追求速度的最理想形态。

### 实战总结口诀

1. **价值**：两面 >> 嵌张 > 边张。
2. **重叠**：回避二度受，1-4重叠先打1。
3. **对子**：两个恰恰好，三个拆一个。
4. **节奏**：序盘追求牌效，中后期（7-10巡）立直高峰期需兼顾防守。
5. **目标**：五组打法奔向完全一向听。
