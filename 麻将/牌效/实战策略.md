# 实战策略

从序盘到听牌，玩家的核心目标是不断减少“向听数”，并在关键的“一向听”阶段完成爆发。

## 阶段优先策略

### 序盘阶段 (1-5 巡)：搭子储备与冗余清理

- **优先舍弃客风牌与幺九牌**：客风牌无役且成牌能力最差，1、9 牌无法组成两面搭子，应最先处理。
- **回避有效牌重复 (二度受)**：若持有 `1、4` 或 `6、9` 筋牌组合，由于有效进张（如 2、3）重叠，1 或 9 的价值甚至低于客风牌，应果断舍弃。
- **保留中心数牌 (3-7)**：这些牌成搭能力最强，是构建好型搭子的基础。

### 中盘阶段 (6-10 巡)：确立“五组”与形状强化

- **执行五组理论**：将手牌拆解为“4 面子 + 1 雀头”，若搭子过多（6 组以上），应拆掉最弱的边张或愚型搭子。
- **处理对子矛盾**：两个对子协作最强（双碰效应），若有三个对子则建议拆掉其中一个，将其转化为面子搭子。
- **攻守平衡预警**：此阶段立直概率进入巅峰，若手牌进度慢，需开始保留安全牌。

### 听牌冲刺阶段 (一向听)：一向听集中理论

- **牺牲改良换取速度**：此阶段是进张最难、难度最高的阶段，应追求“直接进张”数量最大化。
- **追求“完全一向听”**：理想形态应包含两个两面搭子、一个对子复合型及一个独立对子。
- **减少受阻结构**：如 `1224` 或 `1334` 等互相抢夺进张的结构，应通过拆牌转化为更灵活的复合型（如 `334`）。

## 牌型价值综合评估表

牌型价值的关键结论：

1. **位置定胜负**：即使形状相同，**中心位置**复合型的“好型进张数”远超**边张位置**。
2. **四连型与中膨型的优越性**：中心位置的四连型和中膨型几乎所有进张都能转化为两面以上的好型，是牌理中的最高级形状。
3. **边张复合型的陷阱**：边张位置的复合型（如 1223 或 1112）虽然名义上进张不少，但极难形成两面听牌，在一向听阶段应优先考虑改良或拆除。
4. **螺丝型的多功能性**：中心螺丝型（3444）在缺头时能充当对子，在需要面子时能转化为顺子，且听牌张数高达 11 张，强度极高。

## 牌型价值评估补充

- **四连型**（连续四张数牌）
  - **不包含边张（如 3456/4567）**：**S级评价**。最强复合型，同花色1-8数牌均为进张，极易形成好型（两面或三面）。以 3456 为例：直接胡两面（3/6），胡牌张数 6。
  - **包含边张（如 1234/6789）**：**B-级评价**。由于12是边张搭子，价值显著下降，其效率在很多情况下仅比单张数牌略高。以 1234 为例：直接胡两面（1/4），胡牌张数 6。

- **中膨型**（顺子中间夹对子）
  - **不包含边张（如 3445/4556）**：**A+级评价**。进张广且形成好型概率极高（进2、3、5、6均可成两面），具备一盃口潜力。以 3445 为例：直接胡单骑（4），胡牌张数 2。
  - **包含边张（如 1223/7889）**：**C级评价**。受边张限制，进张能力显著减弱，价值有时不如单张中张数牌。以 1223 为例：直接胡单骑（2），胡牌张数 2。

- **螺丝型**（暗刻+邻接单张）
  - **不包含边张（大螺丝，如 3444）**：**A级评价**。拆解灵活。以 3444 为例：直接胡三面（2/3/5），胡牌张数 11。
  - **包含边张（小螺丝，如 1112/6888）**：**B级评价**。强度仍不亚于一般两面。以 1112 为例：直接胡两面（2/3），胡牌张数 7。

- **跳张型**（顺子+跳一格的数牌）
  - **不包含边张（最强型，如 3567/3457）**：**A级评价**。进张数极高且改良能力极强。以 2346 为例：直接胡单骑（2），胡牌张数 3。
  - **包含边张（最弱型，如 1345/5679）**：**B-级评价**。虽仍强于单张2/8，但因缺乏一侧延伸空间，进化潜力较低。以 1345 为例：直接胡单骑（1），胡牌张数 3。

- **亚两面**（对子+紧贴的顺子）
  - **不包含边张（如 3345）**：**B+级评价**。缺对子时是优秀候选。以 3345 为例：直接胡两面（3/6），胡牌张数 6。
  - **包含边张（如 1123/7899）**：**B级评价**。强度受手牌对子总数影响很大。以 1123 为例：直接胡两面（1/4），胡牌张数 6。
