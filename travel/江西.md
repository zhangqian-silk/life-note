# 江西

> Git 链接：<https://github.com/zhangqian-silk/life-note/blob/master/travel/江西.md>

## 景点

### 南昌篇 (英雄之城)

作为江西省的省会，南昌是一座交织着历史荣光与现代活力的城市。“八一”军旗在此升起，赋予了它“英雄城”的红色基因；赣江穿城而过，滕王阁矗立江畔，吟诵着千古名篇。这里既有深厚的历史底蕴，又有湖光山色的自然景致，是感悟历史、品味文化、享受生活的绝佳之地。

#### 滕王阁

**一句话亮点**
登临江南三大名楼之首，亲身感受“落霞与孤鹜齐飞，秋水共长天一色”的千古绝唱。

**简要介绍**
滕王阁，因初唐诗人王勃的《滕王阁序》而流芳后世，与黄鹤楼、岳阳楼并称为“江南三大名楼”。它屡毁屡建，如今的滕王阁是1989年重建的，雄踞赣江之滨，以其非凡的气势和深厚的文化底蕴，成为南昌的城市地标。建筑采用宋代风格，飞檐斗拱，画栋雕梁，内部则以壁画、浮雕等形式，生动展现了江西的人文历史。

**核心体验**

- **登楼望远**：拾级而上，直至主阁顶层。凭栏远眺，可见赣江浩荡东流，两岸高楼林立，现代都市的繁华与江水的静谧交相辉映，心胸顿时开阔。
- **品读序文**：阁内陈列着历代名家书写的《滕王阁序》，驻足于巨大的汉白玉浮雕前，默诵“渔舟唱晚，响穷彭蠡之滨”，仿佛能听见历史深处传来的回响。
- **夜游滕王阁**：当夜幕降临，华灯初上，整个滕王阁被璀璨的灯光点亮，金碧辉煌，倒映在江水中，如梦似幻。阁内上演的《寻梦滕王阁》实景演出，更是一场穿越古今的视听盛宴。

**实用贴士**
建议傍晚时分游览，既可欣赏白天的江景，又能等到日落时分的绝美晚霞，并顺便观赏夜景。门票建议通过官方公众号提前预订。夏季登阁较高楼层风大凉爽，但仍需注意防晒。

#### 八一广场 & 八一南昌起义纪念塔

**一句话亮点**
在军旗升起的地方，追忆那段激情燃烧的峥嵘岁月。

**简要介绍**
八一广场是南昌的心脏，也是世界上最大的城市中心广场之一。其核心是高高耸立的八一南昌起义纪念塔，为纪念1927年由中国共产党领导的南昌起义而建。塔身呈长方体，正面镌刻着“八一南昌起义纪念塔”九个大字，塔顶是一面巨大的“八一”军旗雕塑和一支步枪，象征着中国人民解放军的诞生。

**核心体验**

- **瞻仰纪念塔**：缓步走近纪念塔，仰望高耸的塔身与飘扬的军旗，塔座四周的浮雕生动再现了起义的战斗场面，庄严肃穆的氛围让人不禁心生敬意。
- **观赏军乐喷泉**：夜幕降临后，广场上的军乐喷泉会随着激昂的红色音乐翩翩起舞，水柱时而高亢，时而婉转，与变幻的灯光一起，构成一幅壮丽的画卷。
- **融入市民生活**：清晨或傍晚，这里是市民休闲娱乐的聚集地。散步、放风筝、跳广场舞的人们，为这片红色圣地注入了浓浓的生活气息，历史与现实在此和谐共存。

**实用贴士**
八一广场为开放式广场，免费参观。参观纪念塔建议安排在白天，光线好，便于瞻仰细节。晚上8点左右的音乐喷泉是不可错过的亮点，建议提前占据有利观赏位置。

### 九江篇 (匡庐奇秀)

九江，襟江带湖，雄踞长江、鄱阳湖、京九铁路的交汇点。自古便是江南的“鱼米之乡”，更因一座庐山而名扬天下。李白的诗，白居易的词，陶渊明的田园，都为这片土地增添了无穷的诗意与魅力。这里是寻觅山水之奇、人文之胜的理想去处。

#### 庐山

**一句话亮点**
在云雾缭绕的仙境中，探寻千古诗词的源头与自然的鬼斧神工。

**简要介绍**
庐山，以雄、奇、险、秀闻名于世，素有“匡庐奇秀甲天下”之美誉。它不仅是世界文化景观遗产、世界地质公园，更是中华文明的发源地之一。山间气候温润，夏季凉爽，是著名的避暑胜地。历代文人墨客在此留下了四千余首诗词，使得庐山的每一处山石、每一道溪流都浸透了浓郁的文化气息。

**核心体验**

- **飞瀑寻踪**：亲临“飞流直下三千尺，疑是银河落九天”的秀峰瀑布或三叠泉瀑布，感受水汽扑面的清凉与震耳欲聋的轰鸣，体会诗仙李白当年的震撼。
- **云中漫步**：在海拔千米的牯岭镇上小住，清晨推开窗户，便可能看到云海翻腾。漫步在山间小径，时而被浓雾包裹，时而云开雾散，峰峦尽显，宛如仙境。
- **探访名人故居**：游览蒋介石与宋美龄的“美庐”别墅，或是参观庐山会议旧址，触摸近代中国的风云变幻。这些历史建筑静静地坐落在青山翠谷之间，讲述着过去的故事。

**实用贴士**
庐山景点分散，建议购买观光车票，随上随下，方便游览。山上气候多变，早晚温差大，即使是夏季也建议携带一件薄外套。雨后是观赏瀑布和云海的最佳时机。

### 上饶篇 (大美乡村)

上饶，地处四省交界，自古就有“上乘富饶”之美誉。这里拥有中国最美的乡村——婺源，也有道教圣地——三清山，还有世界自然遗产——龟峰。走进上饶，就如同翻开一幅幅浓墨重彩的山水画卷，处处是景，步步皆画。

#### 婺源

**一句话亮点**
走进水墨徽州画卷，看小桥流水人家与梯田花海交相辉映。

**简要介绍**
婺源被誉为“中国最美的乡村”，其徽派建筑的粉墙黛瓦与周边的绿水青山完美融合，构成了一幅恬静自如的田园诗画。春季，漫山遍野的油菜花海金黄夺目；秋季，篁岭古村的“晒秋”景象五彩斑斓。无论是江湾的古镇风韵，还是李坑的小桥流水，都让人流连忘返。

**核心体验**

- **篁岭晒秋**：乘坐缆车登上篁岭，俯瞰层层叠叠的梯田和错落有致的古村落。家家户户的窗台、晒架上，晾晒着火红的辣椒、金黄的玉米和菊花，构成一幅独一无二的“晒秋”民俗画卷。
- **月亮湾泛舟**：在清晨或黄昏，当薄雾轻抚水面时，乘一叶竹筏，在月亮湾的S型河湾中缓缓漂流。看远山如黛，古树倒映，渔夫撒网，感受那份宁静与诗意。
- **古村徒步**：选择一条经典的徒步路线，如从庆源到官坑，穿行于古道、茶园、村落之间，远离喧嚣，用脚步丈量这片土地的美丽，感受最淳朴的乡土人情。

**实用贴士**
婺源景点极为分散，建议包车或自驾游览。游玩婺源的最佳时间是3-4月的油菜花季和10-11月的赏秋季。门票通常是通票形式，可在几天内游览多个景点，注意规划好路线。

#### 三清山

**一句话亮点**
在西太平洋边缘最美的花岗岩上，欣赏堪比黄山的奇峰怪石与云海仙境。

**简要介绍**
三清山是世界自然遗产地，也是一座拥有1600多年历史的道教名山。其独特的花岗岩峰林地貌，被誉为“西太平洋边缘最美花岗岩”。景区内奇峰耸天，幽谷千仞，怪石嶙峋，古松虬劲，云海、霞光、佛光等气象景观更是变幻莫测，引人入胜。

**核心体验**

- **行走高空栈道**：挑战西海岸和阳光海岸的高空栈道，这些栈道悬挂于千米绝壁之上，行走其间，脚下是万丈深渊，眼前是壮阔的峰林，惊险刺激又风光无限。
- **守候日出云海**：在山顶的女神宾馆或玉台附近住下，清晨早起，等待第一缕阳光刺破云层，将连绵的云海和群峰染成金色，那种壮丽的景象足以震撼心灵。
- **细品奇石造型**：充分发挥想象力，欣赏那些大自然鬼斧神工雕琢出的奇石，如“巨蟒出山”的雄伟，“东方女神”的温婉，每一个都有着独特的神韵和故事。

**实用贴士**
游览三清山对体力有一定要求，建议乘坐缆车上下山以节省体力。山上天气变化快，请务必备好雨具和保暖衣物。推荐的游览路线是南上南下或东上东下，可以走一个环线，将核心景区都逛到。

### 景德镇篇 (千年瓷都)

景德镇，一座因瓷器而生、因瓷器而闻名的城市。这里“一城瓷器半城窑”，瓷器的历史长达两千年。熊熊燃烧的窑火，塑造了这座城市的灵魂。如今的景德镇，不仅是陶瓷艺术的圣地，更是一座充满创意与活力的艺术之都。

#### 古窑民俗博览区

**一句话亮点**
穿越时空，亲眼见证从一抔瓷土到一件精美瓷器的神奇之旅。

**简要介绍**
这里是全国唯一一个以陶瓷文化为主题的国家级5A景区，集中复建和再现了景德镇历代瓷窑。从宋代的龙窑到清代的镇窑，这些仍在烧炼的古窑，仿佛是活着的陶瓷历史博物馆。景区内还有非遗传承人现场展示拉坯、利坯、画坯、施釉等传统制瓷手艺，让人叹为观止。

**核心体验**

- **观摩活态传承**：在作坊里，近距离观看白发苍苍的老匠人们，如何用一双巧手，将泥土变成精美的艺术品。每一个步骤都凝聚着千年的智慧与匠心，令人动容。
- **探秘古代瓷窑**：走近巨大的镇窑，感受那古老窑炉的余温与气势。听导游讲解烧窑的复杂工艺和“窑神”童宾的传说，深入了解瓷都的灵魂所在。
- **亲手体验制瓷**：在陶艺中心，亲手体验拉坯或彩绘的乐趣。在专业老师的指导下，制作一件属于自己的、独一无二的陶瓷作品，并可选择快递回家，是最好的旅行纪念。

**实用贴士**
景区较大，建议留出至少半天时间。可以聘请一位讲解员，能更深入地了解陶瓷文化和历史。景区内的瓷器价格偏高，购买需谨慎，但体验制瓷非常值得推荐。

#### 陶溪川文创街区

**一句话亮点**
在由老瓷厂改造的时尚街区，感受传统陶瓷与现代艺术碰撞出的创意火花。

**简要介绍**
陶溪川由原“宇宙瓷厂”的旧厂房改造而成，完美地保留了上世纪的工业建筑风貌，如高耸的烟囱、斑驳的墙壁和老式窑炉。通过现代设计理念的注入，这里已经转变为一个集美术馆、博物馆、工作室、餐饮、酒店于一体的时尚文创地标，尤其在夜晚，灯光璀璨，充满艺术气息。

**核心体验**

- **逛创意集市**：每逢周末，陶溪川的创意集市是最大的亮点。来自全国各地的年轻陶艺家和学生会在这里摆摊，出售自己独具匠心的作品，是“淘宝”和发现新锐设计的好去处。
- **夜拍工业风大片**：夜晚的陶溪川灯光设计极具美感，老厂房、水塔、烟囱在光影下呈现出迷人的后工业风情，是摄影爱好者的天堂，随手一拍都极具格调。
- **参观艺术展览**：街区内的陶溪川美术馆、陶瓷工业遗产博物馆等场馆常年有高品质的展览。花一个下午，沉浸在陶瓷艺术的殿堂里，感受其跨越古今的魅力。

**实用贴士**
陶溪川最美的时刻是晚上，建议下午四五点钟到达，先逛逛室内的美术馆，等到夜幕降临再感受其夜景魅力。周末的集市最为热闹，分为春秋大集和常规的周末集市，可以提前关注其官方公众号获取信息。

## 餐厅

- **南昌拌粉与瓦罐汤**：作为江西美食的代表，几乎在南昌的任何一家早餐店都能品尝到。推荐去绳金塔美食街或一些老字号小店，体验地道的南昌味道。
- **鄱阳湖全鱼宴**：在鄱阳湖边的城市如南昌、九江，可以品尝到以鄱阳湖鲜鱼为原料烹制的盛宴，其中“鄱湖胖鱼头”最为著名，鱼肉鲜嫩，汤汁浓郁。
- **庐山三石宴**：庐山上的特色美食，指“石鸡、石鱼、石耳”，均为当地特产，口味独特，值得一试。山上的牯岭镇有很多餐厅提供。
- **景德镇碱水粑**：景德镇的传统小吃，用大米磨浆，加入碱水蒸熟后切块，可炒可煮，口感爽滑，是当地人记忆中的味道。在陶溪川或市井小巷里都能找到。
- **婺源糊豆腐**：将豆腐、肉末、笋干、香菇等食材烩成糊状，鲜美可口，是婺源一道地道的家常菜，在当地农家乐中广受欢迎。

## 路线参考

### 经典线路组合

- **南昌经典一日游**
  - 上午登临滕王阁，感受“江南第一楼”的气势。
  - 中午品尝南昌拌粉和瓦罐汤。
  - 下午参观八一南昌起义纪念馆，并在八一广场瞻仰纪念塔。
  - 傍晚漫步秋水广场，观赏亚洲最大音乐喷泉。

- **景德镇陶瓷文化二日游**

  - Day 1：上午参观中国陶瓷博物馆，系统了解陶瓷历史 -\> 下午在古窑民俗博览区，看古法制瓷，亲手体验 -\> 晚上夜游陶溪川文创街区，逛创意集市。
  - Day 2：上午探访三宝国际瓷谷，感受更前沿的陶瓷艺术氛围 -\> 下午在雕塑瓷厂或乐天陶社，深入探访艺术家工作室，自由“淘宝”。

- **庐山精华二日游**
  - Day 1（东线）：游览含鄱口，远眺鄱阳湖 -\> 攀登五老峰，挑战体力 -\> 下午探访三叠泉瀑布，感受其磅礴气势。
  - Day 2（西线）：漫步花径，寻访白居易的足迹 -\> 游览如琴湖，享受湖光山色 -\> 参观美庐别墅、庐山会议旧址，了解近代历史风云。

### 路线建议

1. **赣北环鄱阳湖全景之旅（约 7-8 天）**：南昌 → 九江（庐山） → 景德镇 → 上饶（婺源、三清山） → 南昌。

   - **路线特色**：此线路囊括了江西最核心的自然与人文景观，从名楼、名山到瓷都、乡村，内容丰富，体验多样，是初次到访江西的首选经典路线。

2. **赣西道教山水文化之旅（约 5-6 天）**：南昌 → 新余（仙女湖） → 宜春（明月山） → 萍乡（武功山） → 南昌。

   - **路线特色**：以道教文化和山水风光为主题，特别适合户外和登山爱好者。武功山的高山草甸和明月山的温泉，都是极为独特的体验。

3. **赣南红色摇篮与客家风情之旅（约 6-7 天）**：南昌 → 吉安（井冈山） → 赣州（古城墙、郁金台） → 龙南（客家围屋） → 瑞金（共和国摇篮） → 南昌。

    - **路线特色**：一条深度人文之旅，重走革命圣地，追寻红色记忆，同时深入体验独特的赣南客家文化，适合对历史和民俗感兴趣的旅行者。
