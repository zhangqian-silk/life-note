# Windows 专区

本目录集中保存 Windows 原生系统和软件配置，图片随各篇文档一起维护。`launch` 的默认配置流程面向 Linux / macOS。

- [Windows 基础环境](./Basic/Windows.md)：Windows 下的 JDK、Make 等历史配置笔记。
- [PotPlayer](./program/PotPlayer.md)：解码器、渲染器与播放器设置。

如果使用 WSL 2，在 Linux 子系统内执行 [新设备开发环境配置](../Environment.md) 中对应发行版的步骤；Windows 原生安装仍参考本专区。两个环境的 HOME、PATH 和程序安装位置分别管理。
